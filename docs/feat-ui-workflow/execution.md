## Границы доказательств

Локальные installer tests выполнены на macOS, Node v26.5.0 / npm 11.17.0. Существующая CI-матрица Node 18/22 × Ubuntu/macOS удалённо не запускалась, так как push/PR не запрашивались; совместимость API проверена по коду. Четыре приложения-агента не запускались ради проверки распознавания скиллов.

React fixture не содержит установленных зависимостей: `npm run build` завершается `vite: command not found`, browser checks для этого ограниченного прогона запрещены. Его статус остаётся incomplete; источник подтверждает использование общей React-реализации, но React runtime не считается проверенным. Native fixture и отдельные UI review сценарии проверены реальным браузером. Все результаты ограничены перечисленными сценариями, не всеми web-фреймворками.

Временные серверы проверки останавливаются владельцами; пользовательские процессы и установленные личные скиллы не менялись. Старые untracked отчёты двух других задач сохранены.
